# Bike Rental Count Prediction Using Machine Learning

## Project Overview
This project aims to predict daily bike rental demand using machine learning regression algorithms based on historical weather and seasonal data.

## Dataset
Capital Bikeshare dataset (2011–2012):
- 731 daily records
- 17,379 hourly records

## Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Project Implementation
1. Data Collection and Understanding
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Feature Engineering
6. Machine Learning Model Training
7. Model Evaluation and Comparison
8. Final Prediction and Conclusion

## Machine Learning Models
- Ridge Regression
- Decision Tree Regressor
- Random Forest Regressor

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Project Outcome
The project analyzes bike rental patterns and compares regression models to identify a suitable approach for predicting daily bike rental demand.

## How to Run
1. Download the project files.
2. Open the `.ipynb` notebook in Google Colab.
3. Upload the CSV datasets when prompted.
4. Run all notebook cells to reproduce the analysis and predictions.
